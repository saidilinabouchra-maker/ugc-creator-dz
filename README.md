# UGC Creator — Formation Pratique

Landing page للتسجيل في تكوين حضوري تطبيقي في صناعة المحتوى الإعلاني UGC — باب الزوار، الجزائر العاصمة (9,000 دج).

- ملف واحد `index.html` (HTML/CSS/JS بدون مكتبات)، RTL، Mobile First.
- أيقونات ورسومات SVG مدمجة (بدون صور ثقيلة).
- استمارة Google Forms مدمجة وتُحمَّل فقط عند الاقتراب منها + زر لفتحها في صفحة كاملة.
- مكان مخصص لكود Meta Pixel داخل `<head>`.

## النشر على GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.

## النشر على Vercel
New Project → Import هذا المستودع → Framework: `Other` → Deploy (لا حاجة لأي build).
